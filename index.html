HARDWARE NOTE / 001 ✳

Memory sets the ceiling.

The planned RTX 3060 has 12 GB of VRAM. The GTX 1070 has its own separate 8 GB; the two cards do not become one 20 GB pool. That constraint shapes the model choices and expectations.

NETWORK RULE

Keep Ollama port 11434 private and do not expose it or the WebUI directly to the public internet. Tailscale gives authorized tailnet devices a private route; keep WebUI authentication enabled and review who belongs to your tailnet.

06HOW AGENTS WORK

One important distinction

Roles are easy.
Automation is a choice.

Open WebUI can present saved models with different prompts, and Ollama can create named models from a Modelfile. A “router” prompt can recommend a specialist, but it will not automatically call another model by itself. For real delegation, add an explicit workflow or tool integration and grant only the access it needs.

07RUN IT WELL

The boring bits keep it useful

Private by design.
Reliable by habit.

Treat this like any other service in your home lab: keep it patched, keep a restore path, and decide explicitly who can reach it.

01 / ACCESS

Keep the boundary clear.

Don't bind Ollama to every interface as a convenience. If a service must be reachable on your LAN, restrict it with host firewall rules and authenticated access.

02 / BACKUPS

Back up the state that matters.

Back up Open WebUI's persistent data and your Modelfiles. Model weights can usually be downloaded again; chat data and configuration may not be.

03 / UPDATES

Change one thing at a time.

Pin container versions for stable service, record model tags, and test upgrades before relying on a changed model or prompt.

08FIELD QUESTIONS

A few quick clarifications

Before you
power it up.

Will the RTX 3060 and GTX 1070 give me 20 GB of VRAM?

No. Their memory pools stay separate. Ollama may spread a model across devices in some configurations, but this is not a single, fungible 20 GB pool. Plan around the model's actual allocation and leave room for context.

Does each agent need its own model download?

Not necessarily. Ollama-created models can share the same underlying layers when they use one base model. Keep a separate coding model only when its capabilities justify its extra disk and memory use.

Can I open this up for Home Assistant and my phone?

Prefer a private VPN such as Tailscale for remote access. For a local integration, use the server's LAN address only after checking authentication and firewall behavior. Never publish the Ollama API directly to the internet.

Can the coordinator automatically hand work to agents?

Not from a system prompt alone. You need an orchestration layer or tool workflow that explicitly invokes specialist models and passes their results back.
